### 📊 Data Jobs Dashboard (V2 – Single-Page Overview)

This is the second version of my Data Jobs Dashboard project, redesigned into a single-page layout to make it easier to explore the 2024 data job market. It provides an overview of job postings, required skills, and salary information, helping users compare job titles and identify popular skills.

![Data Jobs Dashboard V2](/images/Project2_Page1.png)

### **🛠️ Key Power BI Skills Utilized (V2):**

- 🎨 **Dashboard Design:** Creating a clean, single-page layout for easier data exploration.
- ⚙️ **Power Query Transformations:** Cleaning, shaping, and preparing data for analysis.
- 🔗 **Star Schema Data Modeling:** Building table relationships to organize data efficiently.
- 🧮 **DAX Measures:** Using `CALCULATE` and other DAX functions to create calculations and analyze data.
- 📊 **Dynamic Visualizations:** Using charts and slicers to explore job market trends.
- ⚙️ **Field & Numeric Parameters:** Allowing users to switch between different metrics and explore salary data.
- 🌍 **Geographic Visualizations:** Exploring job market data by location.
- 🎯 **KPI Cards:** Displaying key metrics such as job count and median salary.
- 🔍 **Interactive Filtering:** Using slicers and cross-filtering to compare job titles, skills, and salaries.
- ✨ **Dashboard Optimization:** Organizing visuals and information to make the dashboard easier to navigate.
