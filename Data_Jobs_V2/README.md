# Data Jobs Dashboard w/ Power BI

![Dashboard Overview](/images/Project2_Dashboard_Overview.gif)

## Introduction
This dashboard explores the data job market using real-world job posting data. It helps me analyze job titles, salaries, locations, and other market trends to better understand opportunities in the data industry.

The goal of this project is to practice using Power BI to turn raw data into interactive visualizations and useful insights.



## 🛠️ Skills Applied

- 🎨 **Dashboard Design:** Creating clear and easy-to-understand dashboard layouts.
- ⚙️ **Power Query:** Cleaning and transforming data for analysis.
- 🔗 **Data Modeling:** Creating table relationships using Star Schema principles.
- 🧮 **DAX Fundamentals:** Using calculations and aggregations to analyze data.
- 📊 **Data Visualizations:**
  - 📈 **Charts:** Using bar, column, line, and area charts to compare data and identify trends.
  - 🌍 **Maps:** Displaying job market data by location.
  - 🎯 **KPI Cards:** Highlighting important metrics.
  - 📋 **Tables:** Presenting detailed information.
  - 🎨 **Chart Selection:** Using different chart types to present data clearly.
- 🔍 **Interactive Features:**
  - 🎚️ **Slicers:** Filtering data based on selected criteria.
  - 🔖 **Buttons & Bookmarks:** Navigating between dashboard pages and views.
  - ➡️ **Drill-Through:** Exploring more detailed information from the dashboard.


## Dashboard Overview

This is the second version of my Data Jobs Dashboard project. I redesigned it into a single page to make it easier to explore the data job market and find useful information.

![Dashboard Page 1](/images/Project2_Dashboard_Page1.png)

The dashboard provides an overview of the data job market, including:

- **Job Count:** Total number of job postings.
- **Skills Per Job:** Average number of skills required for each job.
- **Median Yearly Salary:** Median annual salary for data-related jobs.
- **Median Hourly Salary:** Median hourly salary for data-related jobs.
- **Popular Skills:** Explore the most in-demand skills based on job count or percentage.
- **Salary Comparison:** Compare salaries across different job titles.


## Conclusion
This updated dashboard (Version 2.0) uses Power BI to turn job posting data into an interactive tool for exploring the data job market. It helps **job seekers, career changers, and professionals exploring new opportunities** compare salaries, discover in-demand skills, and understand job market trends, all in one place.
